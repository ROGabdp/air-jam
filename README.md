# Air Jam 空中即興

放一首你喜歡的歌，用雙手在空中拉出幾條弦，跟著節奏撥。Air Jam 會先「聽」這首歌，找出拍子和每一段的和弦，再把你彈的音自動對到現在的和弦上，所以不會樂器也彈不出難聽的音。

第一個樂器是**空中弦**。之後會加入其他空中樂器。

## 怎麼玩

1. 按「選一首我的歌」（MP3／WAV／M4A）或「用內建示範曲」。
2. 等它聽完這首歌（幾秒鐘）。
3. 先拉幾條弦試試聲音，準備好就按「開始演奏」或空白鍵。
4. 跟著畫面邊緣的閃光和上方的拍點撥弦。踩在拍子上會得到 Perfect／Good 和連擊；沒踩準也一樣好聽，不會扣分。

### 用鏡頭（雙手）

| 動作 | 效果 |
|---|---|
| 兩手都用拇指和食指**捏住**，拉開 | 拉出一條弦；放開後弦會留在空中 |
| 用**食指**劃過弦 | 撥弦。劃得快比較大聲；撥靠近兩端比較亮，撥中間比較圓潤 |
| 一次劃過好幾條弦 | 刷和弦（踩在拍子上、刷到 3 條以上，分數加倍） |
| **握拳**停在一條弦上約 1 秒 | 刪除那條弦 |
| **雙手握拳** 1 秒 | 全部清空 |

弦越長音越低，越短音越高。拉弦的時候旁邊會顯示這條弦現在的音名，弦上的刻度是換音的位置。最多 8 條弦，再多的話最舊的會消失。

### 用滑鼠（沒有鏡頭也能玩）

按 `M` 切換，或在網址後面加 `?mouse=1`。

| 動作 | 效果 |
|---|---|
| 按住左鍵拖曳 | 拉一條弦 |
| 不按鍵，移動滑鼠穿過弦 | 撥弦 |
| 右鍵點弦 | 刪除 |

### 按鍵

| 鍵 | 功能 |
|---|---|
| `空白鍵` | 開始演奏 |
| `1` `2` `3` | 音高模式：和弦內音（預設，怎麼彈都和諧）／歌曲調性的音階（可以彈旋律）／自由音高（不修正） |
| `T` | 換音色（木吉他／古典吉他） |
| `H` | 顯示或隱藏手的骨架 |
| `M` | 滑鼠模式／鏡頭模式 |
| `Esc` | 提早結束這首歌 |

## 在自己的電腦上打開

需要 Python 和 Chrome／Edge。因為用了 ES module，不能直接雙擊 `index.html`。

**Windows 最簡單的方法：**雙擊 `開始玩.bat`。它會在本機開一個伺服器（127.0.0.1，預設連接埠 8020，被佔用就自動換下一個），再用預設瀏覽器打開遊戲。玩完關掉那個黑色視窗就好。

其他系統，或想自己開伺服器：

```bash
python -m http.server 8010
```

再打開 <http://localhost:8010>（沒有鏡頭用 <http://localhost:8010/?mouse=1>）。鏡頭模式第一次需要網路，下載手部追蹤模型。

不需要安裝任何套件，也沒有建置步驟。

## 隱私

- 你的音樂檔只在這台電腦的瀏覽器裡解碼和分析，**不會上傳**。
- 鏡頭畫面只在本機做手部追蹤，**不會上傳、也不會儲存**。
- 沒有帳號、沒有追蹤。鏡頭模式會從 jsDelivr 和 Google 的伺服器下載 MediaPipe 的程式與模型檔，除此之外沒有其他連線。

## 和弦是程式猜的

拍子、和弦和調性都是程式在瀏覽器裡自動分析出來的，**不一定每個都對**，人聲、鼓聲和複雜的編曲都會干擾它。猜錯的時候你彈出來的仍然是一個三和弦的音，頂多聽起來「有點不一樣」，不會刺耳。

目前的限制：

- 只認得 24 個大三／小三和弦，七和弦、掛留和弦等會被歸到最接近的三和弦。七和弦常常本來就模稜兩可（例如 Am7 也包含完整的 C 和弦），所以這類歌猜錯的比例比較高。
- **人聲很大聲的歌最容易猜錯**：一個拉長的人聲音符，它的泛音聽起來就像一個大三和弦。伴奏清楚、人聲不壓過樂器的歌效果最好。
- 假設整首歌是穩定的 4/4 拍、速度在 70～180 BPM 之間；速度有時會猜成一半或兩倍（尤其是沒有鼓的慢歌），這時拍點仍然對得上，只是畫面上的閃光變成兩倍快。自由速度或中途大幅變速的歌會對不準。
- 整首歌只估一個調性，轉調的歌在「音階」模式下可能不準。
- 如果完全聽不出來，會改用 C 大調五聲音階讓你自由彈，這時不計分。

## 靈感來源

- 一支示範「雙手捏出停在空中的弦、弦長決定音高」的 [Facebook Reel](https://www.facebook.com/reel/1320325243578615)，空中弦的玩法來自這支影片（作者姓名不詳，請以影片連結為準）。
- 那支影片的靈感來源：Pat Metheny 的 42 弦「畢卡索吉他」（Pikasso guitar，Linda Manzer 製作）。
- Casio CT-FS1 電子琴的 Feel Sync 功能：分析歌曲的和弦，讓人怎麼彈都合拍。Air Jam 的「和弦吸附」是受它啟發、自己重新實作的。

## 給開發者

```
index.html, style.css
src/
  main.js                    進入點
  settings.js                所有可調整的數值（SETTINGS）
  i18n/                      介面文字（目前只有 zh-Hant）
  app/                       遊戲外殼：畫面流程、主迴圈、HUD
  core/                      共用模組，不綁定任何樂器
    analysis/                聽歌：拍點、和弦、調性（純函式）
    song/                    內建示範曲與測試用的伴奏合成器（純函式）
    music/                   樂理與音高吸附
    game/                    歌曲時間表、節奏判定與計分
    audio/                   Web Audio 引擎、Karplus-Strong 撥弦、音色與效果鏈
    hands/                   MediaPipe 手部追蹤、手勢辨識、滑鼠輸入
    fx/                      粒子、浮動文字、拍點閃光
  instruments/
    instrument.js            樂器介面與登錄表
    air-strings/             空中弦
tests/                       Node 測試（不需要安裝套件）
docs/                        設計說明與背景研究
```

測試（需要 Node 18 以上）：

```bash
node tests/analysis.test.mjs      # 合成幾首已知答案的伴奏，印出分析出的 BPM、調性、每拍和弦正確率
node tests/instrument.test.mjs    # 撥弦合成、手勢、穿越判定、音高吸附、計分、空中弦的邏輯
```

內建示範曲每次載入時，console 會印出分析結果和正確答案（100 BPM、C–G–Am–F）的比對。在 console 裡可以用 `airJam` 查看目前的狀態。

要加新樂器：照 `src/instruments/instrument.js` 的介面寫一個模組，在登錄表裡加一行；音高、發聲、計分和特效都從 `init(ctx)` 拿到的共用服務取得。要加新音色：在 `src/core/audio/tones.js` 加一組撥弦參數和效果鏈。
