# Air Jam 空中即興

放一首你喜歡的歌，用雙手在空中拉出幾條弦，跟著節奏撥。Air Jam 會先「聽」這首歌，找出拍子和每一段的和弦，再把你彈的音自動對到現在的和弦上，所以不會樂器也彈不出難聽的音。

第一個樂器是**空中弦**。之後會加入其他空中樂器。


**直接在瀏覽器玩：https://rogabdp.github.io/air-jam/**（建議用 Chrome 或 Edge）
## 怎麼玩

1. 在開始畫面選**操作方式**：「鏡頭」（用雙手）或「滑鼠」（沒有鏡頭也能玩）。
2. 按「選一首我的歌」（MP3／WAV／M4A）或「用內建示範曲」。
3. 等它聽完這首歌（幾秒鐘）。
4. 先拉幾條弦試試聲音，準備好就按「開始演奏」或空白鍵。
5. 跟著畫面邊緣的閃光和上方的拍點撥弦。踩在拍子上會得到 Perfect／Good 和連擊；沒踩準也一樣好聽，不會扣分。

### 畫面上的按鈕

所有設定都可以直接按按鈕，選好的設定會記在這台電腦的瀏覽器裡，下次打開還在。

- **開始畫面：**「操作方式」切換鏡頭／滑鼠、選歌、「音色實驗室」。
- **準備畫面：**「開始演奏」、「效果器（P）」（調效果器）、「設定」。
- **右上角「設定」（齒輪）**，準備和演奏時都能打開，目前的選擇會亮起來：
  - 音色：木吉他／古典吉他／電吉他
  - 音高：和弦（預設，怎麼彈都和諧）／音階（這首歌調性的音階，可以彈旋律）／自由（不修正）
  - 效果器：顯示或隱藏下方的腳踏區、「調音色」（開始演奏前才能調）
  - 操作方式：鏡頭／滑鼠，以及要不要畫出手的骨架
  - 慣用手：右手／左手（刷弦的手；娃娃音的直條放在另一隻手那邊）
  - 拍子：節拍器、慢一半、快一倍、÷1.5、×1.5、拍點提早、拍點延後、還原（見下面「拍子不對的時候」）
  - 進階：根音保護（電吉他用，見下面）
  - 「完成」、「換一首歌」、「音色實驗室」
- 用鏡頭玩的時候，按鈕也可以用手按：手張開指著按鈕（按鈕會亮一圈），**捏一下再放開**就是按下。手停在按鈕上的時候不會拉弦或撥弦。
- 每個按鈕旁邊的小方框是它的鍵盤快捷鍵（見下面「按鍵」）。

### 用鏡頭（雙手）

| 動作 | 效果 |
|---|---|
| 兩手都用拇指和食指**捏住**，拉開 | 拉出一條弦；放開後弦會留在空中 |
| 用**食指**劃過弦 | 撥弦。劃得快比較大聲；撥靠近兩端比較亮，撥中間比較圓潤 |
| 一次劃過好幾條弦 | 刷和弦（踩在拍子上、刷到 3 條以上，分數加倍） |
| **握拳**停在一條弦上約 1 秒 | 刪除那條弦 |
| **雙手握拳** 1 秒 | 全部清空 |

弦越長音越低，越短音越高。拉弦的時候旁邊會顯示這條弦現在的音名，弦上的刻度是換音的位置。最多 8 條弦，再多的話最舊的會消失。

### 用滑鼠（沒有鏡頭也能玩）

在開始畫面或「設定」裡的「操作方式」選「滑鼠」（或按 `M`）。

| 動作 | 效果 |
|---|---|
| 按住左鍵拖曳 | 拉一條弦 |
| 不按鍵，移動滑鼠穿過弦 | 撥弦 |
| 右鍵點弦 | 刪除 |

### 按鍵

按鍵都是畫面上按鈕的快捷鍵，不用記也能玩。

| 鍵 | 功能 |
|---|---|
| `空白鍵` | 開始演奏 |
| `1` `2` `3` | 音高模式：和弦內音（預設，怎麼彈都和諧）／歌曲調性的音階（可以彈旋律）／自由音高（不修正） |
| `T` | 換音色（木吉他／古典吉他／電吉他） |
| `H` | 顯示或隱藏手的骨架 |
| `M` | 滑鼠模式／鏡頭模式 |
| `Esc` | 提早結束這首歌 |
| `[` `]` | 拍子不對：速度慢一半／快一倍 |
| `;` `'` | 拍子不對：速度 ÷1.5／×1.5（例如 107 ↔ 160 BPM） |
| `,` `.` | 拍點整個往前／往後移一點 |
| `0` | 還原成自動分析的速度 |
| `K` | 節拍器：演奏時每一拍發出滴答聲 |

### 拍子不對的時候

打開「設定」，右邊就是「拍子」的按鈕。建議先按「節拍器」再開始演奏，聽聽滴答聲有沒有跟歌對上：太快就按「慢一半」，太慢就按「快一倍」；如果滴答聲和歌一直像在「三對二」地打架，試試 ÷1.5 或 ×1.5；速度對但總是落在兩拍中間，就按「拍點提早／延後」。演奏中也可以打開「設定」或直接按上面的鍵，「還原」會回到自動分析的結果。

### 電吉他（搖滾用）

在「設定」的音色選「電吉他」（或按 `T`），適合配搖滾歌。預設的聲音是接了過載和破音效果器的電吉他（音色實驗室選出來的「丁」）：靠琴橋撥弦、延音長、左右各一軌，新的一刷會收掉上一刷。有破音的時候，弦只會彈出**強力和弦**：畫面上的和弦會寫成 `A5`、`E5` 這樣，意思是只有根音和五度（例如 A5 就是 A 和 E），沒有決定大調或小調的三度。破音加上完整的三和弦會糊成一團，而且搖滾歌裡的大小調程式常常猜不準；拿掉三度之後，猜錯大小調也聽不出來。

- 換和弦的時候，上一個和弦還在響的音會很快收掉（不到 0.1 秒），不會和新和弦打架。
- 和弦的根音只會用這首歌調性裡搖滾常用的幾個（例如 A 小調的歌是 A、C、D、E、F、G），程式猜到調外的根音時，會沿用前一個和弦。這叫「根音保護」，想聽沒有保護的樣子，在「設定」的「進階」把它關掉。
- 把過載和破音都關掉（效果器板的「清音」），就是乾淨的電吉他，弦會改回彈完整的三和弦。

### 效果器板（測試中）

畫面下方是一排效果器（腳踏區）：捏一下（滑鼠點一下）開關，捏住上下拖（滑鼠按住拖）轉旋鈕，`4`～`9` 鍵也能開關；開始演奏前按「效果器（P）」或「設定」裡的「調音色」可以選預設組、調旋鈕。不想看到腳踏區，在「設定」關掉「顯示腳踏區」。

**娃娃音、過載和破音已經有聲音**（電吉他音色才有作用，演奏中也可以開關、轉旋鈕）；合聲、延遲、空間還沒有聲音，會變暗、標「即將推出」，不能開關，之後再做。

| 預設組 | 聲音 |
|---|---|
| 清音 | 過載、破音都關：乾淨的電吉他，彈三和弦 |
| 微破 | 只開過載：輕輕刷幾乎是乾淨的，用力刷才會破 |
| 搖滾 | 過載＋破音：音色實驗室的「丁」 |
| 重金屬 | 過載＋更重的破音：比搖滾更破、更毛、延音更長 |

「破音程度」旋鈕一起轉過載和破音的增益，轉到最上面那一段會帶出更粗糙、不對稱的破音；「明亮度」調高頻。簡單模式會自動配平音量，破音轉大、轉小，聽起來差不多一樣大聲。

#### 娃娃音（哇哇聲）

腳踏區最左邊的「娃娃音」打開後（可以疊在任何預設組上；預設組都不含娃娃音，換預設組會把它關掉，要再打開一次），有兩種玩法，用它旁邊的「手控／自動」按鈕或 `W` 鍵切換：

- **自動（預設）：**每刷一下，聲音就「哇」一聲張開再收回來，刷得越用力張得越開。只用一隻手、用滑鼠也能玩。
- **手控：**畫面邊緣出現一條直條：右手刷弦的人在**左邊**（鏡頭畫面是鏡像，你的左手就在左邊），左撇子在「設定 → 慣用手」選「左手」，直條就換到右邊。把另一隻手伸進直條，**手越高聲音越亮、越低越暗**；手離開直條，聲音就停在最後的位置。手在直條裡不會撥到弦或拉出弦。用滑鼠時，把游標移進直條上下移動就可以（滑鼠一次只能做一件事：先刷，再移過去）。
- **範圍**旋鈕：轉大，「哇」的高低差更大；轉小比較含蓄。
- 進階模式（「效果器（P）」→「進階」→ 點娃娃音）有完整的旋鈕：自動跟著「刷弦」或「拍子」（跟拍子時每拍掃一次，跟歌的拍子對齊，用拍子按鈕把速度減半或加倍也一樣）、低點、高點、共鳴、靈敏度、張開、收回、音量。

娃娃音只改變聲音，不會讓弦改彈強力和弦（只有過載和破音會）。簡單模式下，娃娃音開或關、踏板在哪裡，音量都差不多（量測約在 ±1 dB 內）。

### 音色實驗室（試聽電吉他音色）

這是用來比較電吉他破音聲音的試聽頁面：在開始畫面或「設定」裡按「音色實驗室」，頁面左上角的「← 回到遊戲」可以回來。選一首歌（或用內建示範曲），它會重複播放歌裡的一段（預設從第 10 秒附近開始、8 小節），再配上一段固定的刷法，你可以一邊聽一邊切換四種音色，比較哪一種最像「接了效果器的電吉他」。四種音色的平均音量已經對齊歌曲，比的是音色，不是大小聲。

| 音色 | 內容 |
|---|---|
| 甲 | 之前遊戲裡的電吉他破音（對照） |
| 乙 | 只把破音加重（前面多一級推升，總增益約 46 dB） |
| 丙 | 乙＋撥弦聲音更像電吉他（靠琴橋撥）、延音更長、新的一刷會收掉上一刷 |
| 丁 | 丙＋比較厚的低頻＋雙軌（左右各一軌，比較寬）。**選了這一組：現在遊戲的電吉他就是丁（效果器板的「搖滾」）** |

按鍵：`1` `2` `3` `4` 切換甲乙丙丁（歌不會重來）　空白鍵 播放／停止　`P` 換刷法（像真人的刷法／八分音符悶刷／每小節一刷）　`S` 歌靜音　`G` 吉他靜音　`←` `→` 段落前後移一小節　`L` 4／8 小節　`-` `=` 吉他小聲／大聲。畫面上也都有按鈕。選好了可以按「複製目前的設定」貼給開發者，或按「用這個音色自己彈」。這個頁面不會改變遊戲預設的聲音。

## 在自己的電腦上打開

需要 Python 和 Chrome／Edge。因為用了 ES module，不能直接雙擊 `index.html`。

**Windows 最簡單的方法：**雙擊 `開始玩.bat`。它會在本機開一個伺服器（127.0.0.1，預設連接埠 8020，被佔用就自動換下一個），再用預設瀏覽器打開遊戲。玩完關掉那個黑色視窗就好。

其他系統，或想自己開伺服器：

```bash
python -m http.server 8010
```

再打開 <http://localhost:8010>（沒有鏡頭就在開始畫面選「滑鼠」）。鏡頭模式第一次需要網路，下載手部追蹤模型。

### 開發者選項（網址參數）

玩家不需要這些；它們只在這一次打開時有效，不會改掉記住的設定。

| 參數 | 作用 |
|---|---|
| `?mouse=1`（`0`） | 用滑鼠模式（鏡頭模式）開始 |
| `?tone=steel`／`nylon`／`electric`／`labA`～`labD` | 指定音色；`labA`～`labD` 是音色實驗室的甲乙丙丁，只能這樣打開 |
| `?keyguard=off`（`on`） | 關掉（打開）電吉他的根音保護 |
| `?pedals=0`（`1`） | 隱藏（顯示）腳踏區 |
| `?lab=1`、`?lab=1&song=<相對路徑>` | 直接打開音色實驗室，並載入和遊戲放在一起的歌（例如本機範例） |

不需要安裝任何套件，也沒有建置步驟。

## 隱私

- 你的音樂檔只在這台電腦的瀏覽器裡解碼和分析，**不會上傳**。
- 鏡頭畫面只在本機做手部追蹤，**不會上傳、也不會儲存**。
- 沒有帳號、沒有追蹤。鏡頭模式會從 jsDelivr 和 Google 的伺服器下載 MediaPipe 的程式與模型檔，除此之外沒有其他連線。

## 和弦是程式猜的

拍子、和弦和調性都是程式在瀏覽器裡自動分析出來的，**不一定每個都對**，人聲、鼓聲和複雜的編曲都會干擾它。猜錯的時候你彈出來的仍然是一個三和弦的音，頂多聽起來「有點不一樣」，不會刺耳。

目前的限制：

- 只認得 24 個大三／小三和弦，七和弦、掛留和弦等會被歸到最接近的三和弦。七和弦常常本來就模稜兩可（例如 Am7 也包含完整的 C 和弦），所以這類歌猜錯的比例比較高。
- **人聲很大聲的歌最容易猜錯**：一個拉長的人聲音符，它的泛音聽起來就像一個大三和弦。伴奏清楚、人聲不壓過樂器的歌效果最好。
- 假設整首歌是穩定的 4/4 拍、速度在 70～180 BPM 之間；速度有時會猜成一半或兩倍（尤其是 70～80 BPM 左右的慢歌），這時拍點仍然對得上，只是畫面上的閃光變成兩倍快。可以用上面的按鈕或按鍵自己修正。自由速度或中途大幅變速的歌會對不準。
- 整首歌只估一個調性，轉調的歌在「音階」模式下可能不準。
- 如果完全聽不出來，會改用 C 大調五聲音階讓你自由彈，這時不計分。

## 給開發者

```
index.html, style.css
src/
  main.js                    進入點
  settings.js                所有可調整的數值（SETTINGS）
  i18n/                      介面文字（目前只有 zh-Hant）
  app/                       遊戲外殼：畫面流程、主迴圈、HUD、設定面板（menu.js）、記住的設定（prefs.js）、用手按按鈕（hand-buttons.js）
  core/                      共用模組，不綁定任何樂器
    analysis/                聽歌：拍點、和弦、調性（純函式）
    song/                    內建示範曲與測試用的伴奏合成器（純函式）
    music/                   樂理與音高吸附
    game/                    歌曲時間表、節奏判定與計分
    audio/                   Web Audio 引擎、Karplus-Strong 撥弦、音色與效果鏈
    hands/                   MediaPipe 手部追蹤、手勢辨識、滑鼠輸入
    fx/                      粒子、浮動文字、拍點閃光
    pedals/                  效果器板的介面與手勢（娃娃音、過載和破音有聲音；哪幾顆可以用：availability.js）
  instruments/
    instrument.js            樂器介面與登錄表
    air-strings/             空中弦
  lab/                       音色實驗室：循環試聽、固定刷法、量測
tests/                       Node 測試（不需要安裝套件）
tools/tone-lab/              音色量測工具（Node 模型）
docs/                        交接、決定紀錄、設計說明、背景研究、設計挑戰
```

測試（需要 Node 18 以上）：

```bash
node tests/analysis.test.mjs      # 合成幾首已知答案的伴奏，印出分析出的 BPM、調性、每拍和弦正確率
node tests/instrument.test.mjs    # 撥弦合成、手勢、穿越判定、音高吸附、計分、空中弦的邏輯
node tests/pedalboard.test.mjs    # 效果器板：資料、捏一下／拖旋鈕、防連按、腳踏區裡不能拉弦或撥弦
node tests/menu.test.mjs          # 記住的設定和網址參數、還沒有聲音的效果器不能開、用手按按鈕不會撥到弦
node tests/samples.test.mjs       # 只在本機：用 samples/ 裡的 WAV 檢查真實歌曲的拍子（沒有檔案就跳過）
node tests/tone-lab.test.mjs      # 削波曲線、濾波器、效果鏈、實驗室音色與刷法
node tests/electric-rig.test.mjs  # 電吉他效果器：旋鈕對應、預設組、自動配平音量、切換不爆音、強力和弦規則
node tests/wah.test.mjs           # 娃娃音：頻率和 Q、平滑、自動娃娃音、跟拍子（改速度也對齊）、音量補償
node tools/tone-lab/measure.mjs   # 量測四個預設組和破音範圍的兩端（加 --set lab 量甲乙丙丁，--set wah 量娃娃音）
```

在音色實驗室的 console 執行 `await airJam.lab.measure()`，會用瀏覽器真的音訊圖（OfflineAudioContext）跑同一套量測。

內建示範曲每次載入時，console 會印出分析結果和正確答案（100 BPM、C–G–Am–F）的比對。在 console 裡可以用 `airJam` 查看目前的狀態。

要加新樂器：照 `src/instruments/instrument.js` 的介面寫一個模組，在登錄表裡加一行；音高、發聲、計分和特效都從 `init(ctx)` 拿到的共用服務取得。要加新音色：在 `src/core/audio/tones.js` 加一組撥弦參數和效果鏈。
