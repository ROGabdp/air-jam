# 效果器研究：經典效果器怎麼運作、瀏覽器裡怎麼做、Air Jam 要放哪些

狀態：研究，部分採用（2026-11-25）：先修破音再做效果器板（[D-015](決定紀錄.md)），選定「丁」當電吉他基礎（[D-017](決定紀錄.md)）；第一批效果器、商標與授權結論照這份文件。

起因：擁有者配搖滾演奏曲試玩電吉他音色後，覺得「聽起來不像有接效果器」，配搖滾怪怪的；希望破音更強、玩家可以調參數（破音量、音色、音量…），並在遊戲裡放一組**虛擬效果器**，用手開關、轉旋鈕。參考了 BOSS DS-1 Distortion 和 SD-1 Super OverDrive，問有沒有公開的各廠牌演算法。

現在的電吉他鏈見 [設計說明.md](設計說明.md) 15.1.1，這份文件不重複。

## 1. 經典效果器的原理與公開分析（2026-11-25）

### 1.1 結論先講

- **有公開的演算法，但不是廠商公開的。** 廠商不公布演算法；公開的是：(1) 愛好者和學者從電路圖做的分析（ElectroSmash、Coda Effects、LTspice 模擬），(2) 學術論文（Stanford CCRMA 的 David Yeh、DAFx 研討會），(3) 開源程式（Faust 函式庫、Guitarix、chowdsp 等）。
- **電路本身大多沒有專利保護**，圖也早就公開；問題在名字、商標和外觀（見第 3 節）。
- 經典破音效果器的核心幾乎都是同一件事：**「削波前的濾波器 → 削波（二極體或電晶體）→ 削波後的濾波器」**。每台聲音不同，主要差在：削波前把哪些頻率推進去削（低音進不進去）、硬削還是軟削、對不對稱、削波後的音色控制是凸中頻還是挖中頻。
- Yeh、Abel、Smith（DAFx-2007）正是把 Distortion 和 Tube Screamer 簡化成「調整濾波器＋無記憶削波曲線＋等化濾波器」三段，參數從電路分析推出來，論文說這樣能抓到原機的大致個性。這就是 Air Jam 現在的架構（`WaveShaperNode` 前後加 EQ），所以**架構不用換，要換的是每段的內容和級數**。

### 1.2 各類效果器

| 類型 | 代表機種（只作參考） | 主要電路段 | 聲音特色從哪來 |
|---|---|---|---|
| Overdrive | Tube Screamer TS808／TS9 | 輸入緩衝 → 運算放大器增益級，兩顆矽二極體**放在回授迴路裡**（軟削波） → 削波後低通 → 主動高音控制 → 輸出緩衝 | 回授迴路裡的 4.7 kΩ＋0.047 µF 形成約 **720 Hz 高通**：720 Hz 以上增益約 12～118 倍（約 21～41 dB），以下幾乎不放大，所以**低音不進削波**；加上削波後約 720 Hz 的低通，形成有名的**中頻凸起（mid hump）**。對稱削波，以奇次諧波為主。常拿來推音箱或推下一顆破音，讓聲音變緊、變集中 |
| Overdrive | BOSS SD-1 | 架構和 TS 類似（回授迴路軟削波） | **不對稱削波**：回授迴路裡一邊兩顆、一邊一顆二極體（2:1），產生偶次諧波，比 TS 多一點「有毛邊的厚度」 |
| Overdrive | Klon Centaur | 內部升壓到約 18 V（更大的動態空間）；增益級後兩顆鍺二極體硬削；**乾淨訊號一直混在裡面**，用雙聯可變電阻調比例 | 乾淨路徑在約 500 Hz 有低通，加強中頻凸起；增益不高時二極體幾乎不作用，比較像「透明的推力」 |
| Distortion | BOSS DS-1 | 輸入緩衝 → **電晶體推升級**（兩段串聯高通先削低音，約 +35 dB，本身也帶一點失真）→ 運算放大器增益級 → **1N4148 二極體接地硬削**（約 ±0.7 V）→ Big Muff 式音色控制 → 輸出緩衝 | 硬削、兩級增益，聲音緊、兇。音色鈕是低通和高通的混合，中間位置在**約 500 Hz 挖下去**（mid scoop），本身造成約 12 dB 音量損失 |
| Distortion | ProCo RAT | 運算放大器（LM308）高增益級，增益最高約 67 dB（理論值，實際被二極體和運放限制），增益和頻率有關 → 二極體接地硬削 → 「Filter」低通鈕 | LM308 的**迴轉率很慢**（約 0.3 V/µs），高增益時高頻自然被壓掉，削波本身就偏暗、偏粗；Filter 鈕是一個可調低通 |
| Fuzz | Fuzz Face | 兩顆電晶體、很少零件，有回授 | 削得非常重、不對稱；偏壓點決定聲音（偏壓不對會變成「噗噗」的斷續聲）；**吉他音量轉小就變乾淨**（對輸入大小非常敏感）；放在鏈的第一顆 |
| Fuzz | Big Muff | 4 級共射放大：推升 → 兩級削波（各有二極體）→ 被動音色控制 → 輸出推升 | 長延音、很厚；音色控制是低通和高通混合，中間在**約 1 kHz 挖下去** |
| Wah | Cry Baby（Dunlop 的商標） | 電感＋電容的**共振帶通**，踏板改變可變電阻 → 改變共振頻率 | 窄的共振峰在約 400 Hz～2 kHz 之間移動。Julius O. Smith 的數位版：共振頻率 fr = 450·2^(2.3·w)（w 是踏板 0～1，450 Hz → 約 2.2 kHz）、Q = 2^(2(1−w)+1)（8 → 2）、增益 0.1·4^w；係數用一階平滑器（極點 0.999）避免拉鍊聲 |
| Chorus | BOSS CE-2 | 1024 級 BBD（類比延遲晶片 MN3007／MN3207）＋時脈產生器，三角波 LFO 調變延遲時間；乾溼混合 | 只有 Rate、Depth 兩個鈕；BBD 前後必須有低通，所以溼訊號偏暗、偏溫暖 |
| Phaser | MXR Phase 90 | **4 級全通濾波器**，JFET 當可變電阻，LFO 推 JFET；和乾訊號混合 | 4 級全通和乾訊號相加，產生 **2 個凹口**上下移動；只有 Speed 一個鈕 |
| Delay | 類比（BBD）vs 數位 | BBD：時脈決定延遲時間，前後低通；數位：取樣存起來再播 | 類比的回音一次比一次**暗、略為晃動**（濾波、時脈抖動）；數位的回音每次都一樣清楚 |
| Reverb | 彈簧、板、房間 | 彈簧／板是機械裝置；數位多用卷積或演算法（全通＋梳狀） | 搖滾節奏吉他通常只有短的房間感；主奏比較多 |
| Compressor | 光學／VCA 壓縮 | 偵測音量 → 自動降增益 | 延音變長、刷弦平均；放在破音前 |
| Noise gate | — | 低於門檻就關 | 真吉他破音時去掉嘶聲和嗡聲（**Air Jam 是合成的聲音，沒有底噪，不需要**，見 4.3） |
| 音箱／喇叭箱 | 4×12、2×12 喇叭箱 | 音箱前級、後級、喇叭箱 | 喇叭箱是破音好不好聽的關鍵：大約 100 Hz 以下和 5 kHz 以上快速衰減。Faust 的 `speakerbp(130,5000)`（依實測 Celestion G12 喇叭）就是兩個 130 Hz 隔直流＋4 階 5 kHz 低通 |

## 2. 瀏覽器裡實際可行的做法（2026-11-25）

### 2.1 可以用的 Web Audio 積木

| 節點 | 用在哪 | 注意 |
|---|---|---|
| `WaveShaperNode` | 所有削波 | `oversample` 可設 `'none'`、`'2x'`、`'4x'`：先升取樣再套曲線再降回來，減少混疊（MDN，直接讀取 https://developer.mozilla.org/en-US/docs/Web/API/WaveShaperNode/oversample ）。輸入超出 −1～1 會被夾住（現在的 `shapeSample` 也是照這個模型）。曲線是靜態的，**沒有記憶**，做不出 Fuzz Face 那種隨輸入大小改變偏壓的效果 |
| `BiquadFilterNode` | 所有 EQ、wah | 類型：lowpass、highpass、bandpass、lowshelf、highshelf、peaking、notch、allpass。都是 2 階；**要 1 階（6 dB/八度，像電路裡的 RC）用 `IIRFilterNode`**。頻率、Q、增益都是 AudioParam，可以用 LFO 或手勢平滑地推 |
| `IIRFilterNode` | 1 階高通／低通（TS 的 720 Hz、Big Muff 式音色控制） | 係數建立後不能改；要可調就準備幾組交叉淡入，或用 biquad 近似 |
| `ConvolverNode` | 殘響、喇叭箱脈衝響應 | 現在的木吉他已經用程式產生的衰減雜訊當殘響 |
| `DelayNode`＋`OscillatorNode`（LFO）＋`GainNode` | chorus、flanger、vibrato、delay | **有回授的迴圈裡一定要有 `DelayNode`**，最短一個處理區塊（128 個取樣，約 2.7 ms @48 kHz），所以 flanger 最短的延遲受這個限制 |
| `DynamicsCompressorNode` | 壓縮 | 參數固定的壓縮器（threshold、knee、ratio、attack、release）；會自動補增益（設計說明已記錄過這個問題） |
| `AudioWorkletNode` | 自己寫的逐取樣處理：二極體削波 ODE、WDF、neural、noise gate | 處理區塊 128 取樣；在 GitHub Pages 上**可以用**（只有 `SharedArrayBuffer` 需要 COOP／COEP 標頭） |

### 2.2 四種建模方式比較

數字是估計（依經驗和公開資料推算），**沒有在 Air Jam 上實測**。Air Jam 的效果鏈是每個聲部一條（不是每條弦一條），所以下面的成本只要乘上聲部數（現在 1，之後主奏再 1）。

| 做法 | 做法說明 | 聲音 | CPU（筆電） | 增加的延遲 | 難度 | 適合 Air Jam？ |
|---|---|---|---|---|---|---|
| A. 靜態削波＋前後 EQ（現在的做法） | biquad → `WaveShaperNode`（4×）→ biquad | 「像」，夠遊戲用；Yeh 2007 證明參數從電路推出來就能抓到大致個性 | 極低（全部原生節點；整條鏈遠低於 1% 單核） | 4× 超取樣濾波器只有幾個取樣 | 低 | **是，先把這個做好** |
| B. 多級削波、頻率相關削波 | 把一台效果器拆成 2～3 級 A：例如 TS 的「乾淨路徑＋（720 Hz 高通→增益→軟削）」相加；DS-1 的「推升軟削 → 硬削 → 挖中頻音色」 | 明顯更像真的；高低音進削波的比例不同，就是 overdrive 和 distortion 聽起來不同的主因 | 低（幾個 WaveShaper，每個 4×） | 同上 | 中 | **是，建議做這個** |
| C. 波數位濾波器（WDF）／二極體 ODE | 在 AudioWorklet 裡逐取樣解電路（牛頓法或查表），通常要 2～8 倍超取樣 | 最接近電路，包括削波和濾波的交互作用、動態反應 | 中：JS 寫 1 個二極體削波器＋8× 超取樣，估計約 1～3% 單核；整台效果器更多 | +1 個處理區塊（約 2.7 ms）以內 | 高；沒有找到成熟的 JS／Web 版 WDF 函式庫（C++ 的 chowdsp_wdf 是 BSD-3，可以編成 WASM） | 之後再說；差別在遊戲裡（手勢延遲約 60 ms、搭配整首歌）大概聽不太出來 |
| D. 神經網路（NAM、LSTM） | 錄真的效果器／音箱，訓練模型，在瀏覽器用 WASM＋AudioWorklet 跑 | 最像錄下來的那台 | 高：WaveNet 標準模型在原生外掛就要幾 % CPU，WASM 估計再慢 1.5～3 倍；有較小的模型 | 約 1 個處理區塊 | 中（有現成的 MIT 播放器），但**旋鈕不能連續調**（一個設定一個模型），而且要找授權乾淨的模型 | 不建議當主要做法 |

神經網路的補充（轉述／搜尋摘要）：TONE3000 開源了 NAM 的瀏覽器播放器，把 NeuralAmpModelerCore（C++）編成 WASM、在 AudioWorkletProcessor 裡跑（https://www.tone3000.com/blog/introducing-the-nam-web-player ；npm `neural-amp-modeler-wasm`）。它用到 `SharedArrayBuffer`，頁面必須跨來源隔離（COOP／COEP 標頭）；**GitHub Pages 不能設定這些標頭**（https://github.com/orgs/community/discussions/13309 ），常見的繞法是 coi-serviceworker（https://github.com/gzuidhof/coi-serviceworker ），但會有重新載入的副作用。

### 2.3 喇叭箱：濾波器還是脈衝響應

- 現在的喇叭箱濾波（高通 75 Hz、兩段低通約 4.5 kHz）和 Faust `speakerbp(130,5000)`（實測 G12 喇叭）的形狀差不多，**方向是對的**。脈衝響應（IR）多的是喇叭錐盆在 2～6 kHz 的一堆小峰谷和更陡的衰減，聽起來比較「像錄音室錄的」。
- 用 IR 的成本：`ConvolverNode` 是原生 FFT 卷積，喇叭箱 IR 通常只要 20～100 ms，CPU 很低。
- **問題是授權**（見 3.1）：免費的喇叭箱 IR 包大多只說「免費下載」，沒寫可以重新散布。可行的做法：(1) 自己錄（有喇叭箱和麥克風才行），(2) 從自己設計的濾波器產生 IR（沒授權問題，但只是把現在的濾波器換個形式，加上自己設計的峰谷才有差別），(3) 找明確寫 CC0／CC BY 的 IR。

### 3.2 商標與外觀（trade dress）

- **電路幾乎保護不了，外觀和名字可以。** 兩個案例（轉述／搜尋摘要，加上 IPWatchdog 文章直接讀取 https://ipwatchdog.com/2025/11/06/no-infringement-intended-my-guitar-pedal-klone-counterfeit-insights-intricacies-trademark-law/ ）：
  - Roland／BOSS 告 Behringer（2005），理由是效果器外觀太像 BOSS；和解，Behringer 改外觀後 Roland 表示已經「夠不一樣」（https://www.mixonline.com/technology/behringer-and-roland-settle-lawsuit-381972 ，轉述／搜尋摘要）。
  - Klon 告 Behringer（2025）：Behringer 的仿製品用了 "Centaur" 這個字、拿劍的人馬圖案、幾乎一樣的金色外殼、類似的旋鈕、外殼上沒有自己的品牌，還在宣傳裡用發明人的照片。改名、改圖、加上自己的品牌後，訴訟撤回。**電路被抄了十幾年都沒事，出事的是名字、圖案和外觀加在一起。**
- **Air Jam 要避免的：**
  - 名字：不要用 BOSS、Ibanez、Dunlop、MXR、ProCo、Electro-Harmonix 等廠牌名，也不要用型號或產品名（DS-1、SD-1、TS、Tube Screamer、Screamer、RAT、Muff、Cry Baby、Phase 90、Klon、Centaur 等），連改字的諧音（像 "Zentara" 這種）也不要。
  - 外觀：不要畫成 BOSS compact 的樣子（長方形外殼、下半部整片可以踩的蓋板、上面兩到三顆黑色旋鈕、型號字樣在踏板上）配上那台的代表色（DS-1 橘、SD-1 黃、CE-2 淺藍）；不要用 MXR 的小方盒加單顆大旋鈕、Klon 的金色外殼、Big Muff 的大鐵盒加印刷圖案。
  - 字型和標誌風格也不要模仿。
- **可以用的：**
  - 類型名稱是通用詞：Overdrive、Distortion、Fuzz、Wah、Chorus、Phaser、Delay、Reverb、Compressor（中文：破音、過載、娃娃音、合唱、相位、迴音、殘響、壓縮）。
  - 「讓人聯想到某一類」的原創設計：建議**不要做成地板上的鐵盒**，而是 Air Jam 自己的視覺語言，例如漂在空中的發光圓盤或寶石，每類一個顏色和圖示（破音＝火焰、合唱＝兩道波、迴音＝同心圓）。顏色本身不是問題，問題是「顏色＋形狀＋字樣」一起像某一台。
  - 文件、credits 裡寫「這顆的聲音參考了 Tube Screamer 類 overdrive 的中頻凸起」這種**說明靈感來源**的用法，和 CLAUDE.md 對 Feel Sync、畢卡索吉他的規則一樣：可以標註，不能拿來當產品或功能名稱，並說明沒有關係。

## 4. 給 Air Jam 的具體建議（2026-11-25）

以下都是**建議，尚未決定**。數字是起點，要用兩首範例歌耳朵調。

### 4.1 為什麼現在「不像有接效果器」（推測）

1. **增益太小、只有一級。** 現在破音的小訊號增益約 24 dB、一個 tanh；真的 distortion（DS-1 推升級約 35 dB 再加運放級）、或「overdrive 推破音音箱」的搖滾標準組合，總增益大很多，削波前還有一級把中頻推起來。只有一級軟削的聲音偏「收音機破掉」，缺少「濃、有延音、壓縮感」。
2. **低音和中頻進削波的比例只有一種。** overdrive 的個性是低音不進削波（720 Hz 以下幾乎不放大），distortion 是整段都進去再挖中頻；現在只有「高通 110 Hz＋750 Hz 小凸」一種折衷。
3. **太乾、太正中間。** 搖滾錄音的節奏吉他通常是左右各錄一軌（範例歌量到的也是左右分開，見 [背景研究與討論.md](背景研究與討論.md) 7.2），Air Jam 的電吉他幾乎在正中間（side −25 dB）、完全沒有空間感，疊在歌上像「從另一個地方傳來的」。這是之前刻意的決定（不要糊進歌的吉他牆），所以要 A/B 比較，不是直接改。
4. 喇叭箱方向是對的（見 2.3），不是主因。

### 4.2 先做的修正（不必等效果器介面）

| 順序 | 改什麼 | 數字（起點） |
|---|---|---|
| 1 | **兩級削波**：在現在的破音前面加一級「overdrive 推升」 | 推升級：乾淨路徑（增益 1）＋〔1 階高通 720 Hz → 增益 ×8～×30（18～30 dB）→ 對稱軟削 tanh〕相加 → 1 階低通約 1.5～3 kHz；再進現在的破音級，破音級的前級增益 +6～+12 dB。總小訊號增益約 40～50 dB |
| 2 | **破音級改成稍硬的削波** | 曲線 y = x / (1 + |x|^n)^(1/n)，n = 2.5（軟）～6（接近硬削），維持一點偏壓（不對稱）和 4× 超取樣；n 可以當「破音個性」參數 |
| 3 | **中頻選擇做成參數**：凸（像 overdrive 推，配樂團比較清楚）或挖（像 DS-1，獨奏時比較大聲兇） | 凸：peaking 800 Hz、Q 0.8、+4～+6 dB（削波前）；挖：削波後 peaking 500 Hz、Q 0.7、−6～−9 dB。**配著歌刷的預設用凸**，因為挖中頻的吉他在混音裡會被貝斯和鼓蓋掉 |
| 4 | **喇叭箱再陡一點**：加第三個低通，並在 2.5～3.5 kHz 加一個小峰（+2 dB、Q 2）模擬錐盆 | 低通 4.5～5.5 kHz，總共約 36 dB／八度 |
| 5 | **很短的房間感**（可以關） | `ConvolverNode`，程式產生 0.4～0.7 秒的衰減雜訊，預延遲 15～20 ms，溼 8～12%；換和弦收音照舊在乾聲上做，殘響很短所以不會拖 |
| 6 | **雙軌（A/B 比較）** | 兩條稍微不同的鏈（破音差 10%、中頻差 100 Hz、其中一條晚 12～18 ms）左右各 70%；或只做 Haas 延遲。對照現在的正中間版本，用兩首範例歌聽 |
| 不需要 | Noise gate | 合成聲音沒有底噪；真吉他的「斷音很乾淨」在 Air Jam 由換和弦收音和 `releaseDepthDb` 負責 |

### 4.3 起步的效果器組（6 顆＋一直開著的音箱）

名字是暫定的中文類型名，**不要用任何廠牌型號**；外觀見 3.2。每顆有開關，旋鈕 2～3 顆，數值 0～1 對應到下面的範圍。

| # | 效果器（暫名） | 旋鈕 | 訊號鏈 | Web Audio 節點 | 聲音目標（只作參考） |
|---|---|---|---|---|---|
| 1 | 推力（Overdrive） | 推力 0～1：高通後增益 ×4～×60（12～36 dB，對數）；音色 0～1：削波後 highshelf 2 kHz −8～+6 dB；音量 0～1：−12～+6 dB | 輸入分兩路：乾淨（×1）＋〔1 階高通 720 Hz（`IIRFilterNode`）→ 增益 → 軟削（對稱 tanh；開「不對稱」時加偏壓 0.1～0.2，像 SD-1）〕→ 相加 → 1 階低通 2.5 kHz → 音色 → 音量 | `IIRFilterNode`、`GainNode`、`WaveShaperNode`（4×）、`BiquadFilterNode` | Tube Screamer／SD-1 類：低音乾淨、中頻凸起、適合推下一顆 |
| 2 | 破音（Distortion） | 破音 0～1：前級 +10～+40 dB；音色 0～1：低通（1 階 ~250 Hz）和高通（1 階 ~1.2 kHz）的混合比例，中間時約 500 Hz 挖 6～8 dB；音量 | 高通 100 Hz（2 階）→ 推升軟削（+15 dB，tanh 帶偏壓）→ 前級增益 → 硬削（n = 4～6）→ 低通 6 kHz → 音色（兩個 `IIRFilterNode` 並聯加兩個增益交叉淡入）→ 音量 | 同上 | DS-1／RAT 類：緊、兇、可以挖中頻 |
| 3 | 娃娃音（Wah） | 位置：**另一隻手的高度**（或「自動」時由撥弦力道帶動）；範圍 0～1：低點 350～500 Hz | 放在破音**前面**；Smith 的公式：fr = 450·2^(2.3·w)、Q = 2^(2(1−w)+1)、增益 0.1·4^w（要乘回來補音量）；用 `bandpass` biquad，頻率和 Q 用 `setTargetAtTime`（約 20 ms）平滑 | `BiquadFilterNode`、`GainNode` | Cry Baby 類；這是 Air Jam 特有的手勢玩法（[背景研究與討論.md](背景研究與討論.md) 4） |
| 4 | 合唱（Chorus） | 速度 0.1～3 Hz；深度 0～3 ms；混合 0～50% | 放在破音和音箱**後面**；兩條 `DelayNode`（基準 8 ms，左右 LFO 相位差 180°）、三角波 LFO → `GainNode`（深度÷1000）→ `delayTime`；溼聲低通 6 kHz（BBD 的暗） | `DelayNode`、`OscillatorNode`、`GainNode`、`BiquadFilterNode`、`ChannelMergerNode` | CE-2 類：清音和主奏好用，節奏破音少用 |
| 5 | 迴音（Delay） | 時間：**跟歌的拍子**（1/8、附點 1/8、1/4，用分析出的 BPM）；回授 0～0.6；混合 0～40% | `DelayNode` → 迴圈裡低通 2.5～4 kHz、高通 150 Hz（類比式回音越來越暗）、可選 0.3 Hz ±0.2 ms 的晃動 → 回授 `GainNode`；最大延遲時間建立時就要給（例如 2 秒） | `DelayNode`、`BiquadFilterNode`、`GainNode`、`OscillatorNode` | 類比延遲；跟拍是 Air Jam 有分析拍子才做得到的加分 |
| 6 | 空間（Reverb） | 大小 0.4～2.5 秒；混合 0～35% | 程式產生 IR（現在木吉他用的 `impulseResponse`）、預延遲 15～30 ms | `ConvolverNode`、`DelayNode`、`GainNode` | 房間到大廳 |
| 常開 | 音箱＋喇叭箱 | 之後可選 2～3 種「音箱個性」 | 4.2 的第 4 點 | `BiquadFilterNode`（或 `ConvolverNode`） | 4×12 喇叭箱 |

先不放：Fuzz（`WaveShaperNode` 做不出 Fuzz Face 那種隨輸入改變的偏壓；可以用「非常不對稱、很重的削波＋無高通」近似，之後再加）、Phaser（4 個 `allpass` biquad，頻率一起由 LFO 推，混 50% 乾聲就有 2 個凹口；簡單，但搖滾節奏用得少）、Compressor（主奏用；`DynamicsCompressorNode` threshold −24 dB、ratio 4、attack 5 ms、release 150 ms，放在破音前）。

**鏈的順序（標準）：** 壓縮 → 娃娃音 → 推力 → 破音 → 音箱／喇叭箱 → 合唱 → 迴音 → 空間。

**節奏和主奏怎麼用：**

| 聲部 | 預設 | 理由 |
|---|---|---|
| 節奏（強力和弦） | 推力（推力 0.3、音量高）＋破音（0.5、中頻凸）＋短空間（10%） | 緊、清楚，不糊進歌的吉他牆；不用迴音和合唱 |
| 主奏（之後） | 壓縮＋推力（0.6）＋破音（0.7）＋迴音（附點 1/8、回授 0.3、混合 25%）＋空間（20%）；娃娃音可選 | 延音長、在混音裡浮出來；**主奏要有自己的效果鏈**（設計說明 15.1.1 已規定聲部分開） |

### 4.4 用手轉旋鈕、開關效果器（2026-11-25）

找到的參考不多，沒有找到「鏡頭追手、空中轉旋鈕」的專門研究：

- VR 旋鈕研究（30 人）比較「握住轉」和「捏住轉」：捏住加上畫圓的動作轉得比較快（轉述／搜尋摘要，https://arpi.unipi.it/bitstream/11568/1161419/1/Evaluation_of_rotation_gestures_in_rotary_vs._motionless_knobs.pdf ）。
- 有 VR 專利用「捏一下開始、轉、再捏一下結束」三段式操作虛擬轉盤（轉述／搜尋摘要）。

給 Air Jam 的建議（自己的推論，未測試）：

- **調旋鈕用「捏住上下拖」，不用「轉手腕」。** 鏡頭每秒約 30 張、延遲約 60 ms，手腕旋轉角（例如從食指根部到小指根部的連線角度）在手正對鏡頭時抖得比位置大；上下拖和現在的捏弦一樣只用位置，比較穩。畫面上還是畫成旋鈕在轉。轉手腕可以當進階選項。
- **捏住才會動**，放開就停在那裡（避免手經過就亂改）；加 3～5% 的死區和平滑。
- **開關**：手指戳一下（像現在撥弦的判定）或握拳往下壓，要有明顯的燈號和音效；加 300 ms 防連按。
- **演奏中不要求調旋鈕**：調效果器放在歌開始前或暫停時的「效果器板」畫面；演奏中只有娃娃音用另一隻手的高度連續控制。
- 每個旋鈕都要有滑鼠操作（滑鼠模式是必備的，CLAUDE.md）。

## 5. 其他有用的（2026-11-25）

### 5.1 怎麼評估破音（可以放進自動測試）

用 `OfflineAudioContext` 跑真的效果鏈（和設計說明 15.1.1 的混音量測一樣）：

| 測試 | 怎麼做 | 看什麼 |
|---|---|---|
| 諧波分佈 | 輸入 110 Hz、−20／−10／0 dBFS 正弦波，看輸出頻譜 | 奇次 vs 偶次諧波（不對稱削波才有偶次）；不同輸入大小時「破的程度」是否漸進 |
| 總諧波失真（THD）對輸入大小 | 輸入從 −40 dB 掃到 0 dB | 從乾淨到破音的轉折點：overdrive 應該比較緩，distortion 比較早就到頂 |
| 頻率相關削波 | 用 80 Hz 和 800 Hz 各別輸入，比較 THD | overdrive 的 80 Hz 應該幾乎不破（720 Hz 高通的效果） |
| 互調失真 | 輸入兩個音（A2＋E3、和 A2＋C#3） | 強力和弦（五度）乾淨、三和弦（含大三度）糊，確認強力和弦的選擇 |
| 混疊 | 輸入 2～5 kHz 正弦波，看有沒有不是整數倍的頻率 | 4× 超取樣夠不夠 |
| 頻率響應 | 很小聲的白雜訊（不進削波） | 各效果器的 EQ 形狀（凸中頻、挖中頻） |
| 耳朵 | 同一段刷法，A/B 切換，疊在兩首範例歌上 | 最後還是要擁有者聽 |
