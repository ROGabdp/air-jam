## D-001　做成給大家玩的完整遊戲，教學版之後再拆（2026-11-25）

- **狀態：**生效
- **誰決定的：**擁有者
- **背景：**這個點子一開始是當作高中生的教學範例在想，受限於學生程度和每週很少的時間。
- **選了什麼：**先做給一般玩家的完整遊戲，品質以玩家體驗為準；之後再從完整專案拆出簡化版本當教學材料，也歡迎學生一起貢獻。
- **沒選的選項：**一開始就照教學範例的程度和進度做（會限制設計和品質）。
- **影響：**CLAUDE.md「這個專案在做什麼」；程式不需要寫給初學者看的註解。

## D-002　遊戲名 Air Jam，空中弦是第一個樂器；不處理撞名（2026-11-25）

- **狀態：**生效
- **誰決定的：**擁有者
- **背景：**原本叫「空中弦」（air-strings），但之後要加其他樂器。
- **選了什麼：**`air-jam`／Air Jam／空中即興，用玩法命名；空中弦保留為第一個樂器名。英文用 air-jam 而不是 jam-air，因為 air 當形容詞放前面比較自然。
- **沒選的選項：**air-strings、strum-the-air、handstrings、no-wrong-notes（綁死在弦樂器或太長）。
- **撞名：**「Air Jam」可能和其他作品同名；擁有者決定不處理，因為這是非營利的遊戲。
- **什麼情況下要重新考慮：**如果要商業化或上架商店。

## D-004　純前端、沒有建置步驟、只用 Web Audio（2026-11-25）

- **狀態：**沿用（未確認）。第一次收尾時誤標成「生效」，2026-11-25 審查後更正；擁有者表示技術部分之後再討論。
- **誰決定的：**Claude 提議（沿用最初教學範例的技術限制），擁有者在決定做成完整遊戲時沒有提出異議，**沒有逐條明確確認**。
- **選了什麼：**原生 ES module、不需要建置、執行時不依賴 npm 套件；聲音只用 Web Audio（不用 Tone.js）；手部追蹤用 MediaPipe Tasks Vision 0.10.14（jsDelivr CDN）。
- **理由：**可以直接發布成靜態網站（GitHub Pages）；音樂和鏡頭都只在玩家的瀏覽器處理，不上傳；之後拆成教學材料時比較容易讀。
- **沒選的選項：**加後端（隱私和維運成本）；Tone.js（多一個依賴，Web Audio 已經夠用）。
- **什麼情況下要重新考慮：**需要即時合成（AudioWorklet）以外的大型音訊處理、或需要多人連線時。

- **誰決定的：**Claude 提議、擁有者同意（同意把「伴奏維持、獨奏另外加按弦」寫進規格）

## D-015　修破音的方式與效果器的順序（2026-11-25）

- **狀態：**生效
- **誰決定的：**擁有者（在 [效果器_設計挑戰.md](效果器_設計挑戰.md) 之後）
- **選了什麼：**先做「音色實驗室」（`?lab=1`），用同一段刷弦在範例歌上比較甲乙丙丁四種音色，聽過再決定預設；效果器分階段做（先預設音色＋過載、破音，再做手勢、娃娃音，合聲、延遲、殘響等之後再做）；玩家主要用預設組合調音色。
- **沒選的選項：**直接照研究一次改完（Fable 量測顯示只照研究改，弦音反而更細）；六顆效果器一起做。
- **背景：**擁有者原本選了六顆效果器（過載、破音、娃娃音、合聲、延遲、殘響），六顆都會做，只是順序拉開。

## D-016　效果器玩法的細節（2026-11-25）

- **狀態：**生效
- **誰決定的：**擁有者（逐項選擇）
- **選了什麼：**
  - **簡單玩法和進階玩法分開：**簡單玩法有預設音色、音量自動配平歌曲、每顆最多兩個旋鈕，確保好聽；進階玩法和真的效果器一樣，有完整旋鈕（含音量）、可以自己排串接順序。
  - **開關：**在效果器開關上「捏一下」。
  - **歌曲中完全用手勢操作：**畫面最下方是「腳踏區」，效果器排成一排、位置固定；手伸進腳踏區時區域亮起，這裡不能拉弦或撥弦；在開關上捏一下切換，切換後 0.4 秒內不會再觸發。鍵盤保留當備援。
  - **娃娃音：**畫面邊緣的滑條＋自動模式。
  - **調音色時：**自動循環試聽（一段歌＋錄好的刷弦），這時弦不發聲。
  - **重破音時新的刷弦收掉上一下的餘音：**要，在實驗室聽過再確認。
  - **清音預設用三和弦**，強力和弦只在破音時用。
  - **s21 判錯的根音：**先在實驗室聽，刺耳再優先修。
  - **做效果器手勢之前，先用鏡頭實測**捏、撥、握拳的準確度。
- **影響：**效果器板和手勢的實作（之後的階段）。

## D-017　電吉他用「丁」當基礎（2026-11-25）

- **狀態：**生效，已實作（commit `dd8332a`～`403a77c`）
- **誰決定的：**擁有者（在音色實驗室聽過甲乙丙丁之後）
- **背景：**擁有者覺得乙、丙像「效果加得不多的電吉他」；丁不錯，而且認為這個做法可以做出類似真的電吉他加效果器的聲音。要更好的話希望能「更破碎」，並且有旋鈕讓自己微調。
- **選了什麼：**遊戲的電吉他預設改成丁（加推力、更硬的削波、靠琴橋撥弦、長延音、重刷收音、補低音、左右兩軌）；效果器板的過載和破音接上真的聲音，破音旋鈕的範圍可以比丁更破碎（最上段帶出不對稱的 fuzz）；四個預設組：清音、微破、搖滾（＝丁）、重金屬。
- **沒選的選項：**甲（現在的音色）、乙（只加推力）、丙（乙加撥弦位置和延音，但很細）。
- **根據：**[效果器_設計挑戰.md](效果器_設計挑戰.md) 開頭的量測、設計說明 15.1.3。
- **之後：**擁有者用滑鼠試玩效果器後覺得效果不錯。
